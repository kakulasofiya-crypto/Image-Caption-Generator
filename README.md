# AI Image Caption Generator

## Overview
The AI Image Caption Generator is an AI-powered application that analyzes uploaded images and generates meaningful captions describing their content. It also helps users understand the objects and scenes present in an image.

## Problem Statement
Build an AI application capable of analyzing uploaded images and generating accurate, meaningful captions that describe the content, while explaining the objects or scenes detected within the image.

## Features
- Upload an image for AI analysis.
- Generate meaningful captions for uploaded images.
- Identify and explain objects or scenes in the image.
- Simple and user-friendly interface.

## Technologies Used
- Python
- Streamlit
- Generative AI API

## Installation and Execution

1. Clone the repository:
   ```bash
   git clone https://github.com/kakulasofiya-crypto/Image-Caption-Generator.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Image-Caption-Generator
   ```

3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your API key in a `.env` file. Never upload your API key to GitHub.

5. Run the application:
   ```bash
   streamlit run app.py
   ```

## Project Objective
To make image understanding easier by automatically generating captions and explaining the visual content using AI.
